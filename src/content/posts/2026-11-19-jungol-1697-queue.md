```python
from collections import *

N = int(input())
q = deque()

for _ in range(N):
    command = input().split()
    if(command[0] == 'i'):
        num = int(command[1])
        q.append(num)
    elif(command[0] == 'c'):
        print(len(q))
    else:
        if not q:
            print('empty')
        else:
            print(q.popleft())
```

### 풀이

`deque`를 큐로 사용했다. `append()`로 뒤에 값을 넣고, `popleft()`로 먼저 들어온 값을 꺼냈다. `c` 명령에서는 `len(q)`로 큐의 크기를 출력했다.

### 얻어간 점

- `from collections import *`는 `collections` 모듈의 공개된 함수·클래스 등을 모두 가져오는 문법이다. 가져온 `deque()`를 바로 사용할 수 있다.
- 자바에서 큐의 크기를 구할 때 쓴 `q.size()`에 해당하는 표현이 파이썬에서는 `len(q)`다.
- `pop()`은 오른쪽, `popleft()`는 왼쪽에서 값을 꺼낸다.
- `if not q`로 큐가 비었는지 확인할 수 있다.
