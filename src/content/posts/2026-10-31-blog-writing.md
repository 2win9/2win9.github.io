> 이 글은 작성 흐름을 설명하는 예시입니다. GitHub 저장소와 Pages CMS를 연결한 뒤 아래 방식으로 운영할 수 있습니다.

## 작성은 웹에서

[Pages CMS](https://app.pagescms.org/)에 로그인한 뒤 `2win9.github.io` 저장소를 선택합니다. ‘글’에서 새 글을 만들거나 기존 글을 열어 수정합니다.

제목과 본문을 작성하고 분류를 선택합니다. 이미지는 본문 편집기에서 업로드할 수 있습니다. 글에 코드를 넣을 때는 Markdown 편집 모드에서 코드 블록을 사용해도 됩니다.

## 저장하면 배포

‘공개’를 켜고 저장하면 GitHub 저장소의 글 파일이 바뀝니다. 준비된 GitHub Actions가 사이트를 다시 만들어 GitHub Pages에 배포합니다.

공개를 끄면 파일은 보관하면서 사이트의 글 목록, 본문 페이지, RSS에서 제외됩니다.

## 수정할 때도 같은 흐름

기존 글을 선택해 필요한 부분을 고친 뒤 저장합니다. 필요하면 수정일을 입력합니다. 글 제목을 바꾸어도 기존 파일 이름을 유지하므로 주소는 그대로 사용할 수 있습니다.

자세한 최초 연결 순서는 프로젝트의 `README.md`에 정리되어 있습니다.
